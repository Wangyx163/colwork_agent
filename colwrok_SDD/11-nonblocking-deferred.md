# 非阻塞后续项

版本：1.3  
本文件只记录 MVP 成功后再做的产品能力；它们不得反向阻塞 P0。

## P1｜单任务体验与可靠性

- 同一 Episode 内的白名单协作结构：多人并行收集、顺序交接、多人参与决策；由负责人复核后展开为基础任务与最小关系，不建立工作流引擎。
- 等待对象、阶段完成计数、已验收版本传递和上游版本变化后的下游失效/重开。
- 同一负责人多条提醒合并、复杂澄清与更细的返工原因。
- 审批长挂起、重试耗尽、更多崩溃点与失败详情页。
- 更完整的上下文窗口、归档导出、筛选和 UI 状态。
- 直属上级/LINE_MANAGER 与 L3 审批；只有组织身份与收件人边界明确后启用。
- 跨 Episode Memory 合并、冲突/衰减和经本人确认后的最小共享。

## P2｜平台化与多任务评测

- 多 ACTIVE Episode、组织权限细化、未参会者外包、真实企微/钉钉/飞书 Adapter。
- `TaskPack + AgentAdapter + EnvironmentAdapter + Scorer`，让同一 Agent 运行不同办公协作任务。
- 更多固定场景与回归样例；可选 LLM 抽取、措辞和缓存。

## P3｜当前项目不排期

- 学术假设、论文式实验、数据集泛化、统计显著性与大规模随机种子扫描。
- 只有项目目标正式变更后，才能通过新 ADR 重新进入范围。
