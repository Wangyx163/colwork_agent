# ADR-026｜分层轻量验收指标

状态：ACCEPTED  
日期：2026-08-05

## 背景

ADR-024 将 P0 指标收敛为四项，避免研究型评测拖垮 MVP；但只有结果与正确性指标不足以解释流程卡点、协调效果和具体节点健康度。

## 决策

P0 使用分层验收看板：

1. 5 个 GATE 只覆盖完整闭环、重复外发、版本/lineage、策略护栏和关键恢复。
2. FLOW SIGNAL 覆盖行动项漏斗、按承诺交付和关键耗时。
3. EFFECT SIGNAL 覆盖触达负担、触达后进展和升级摘要。
4. NODE SIGNAL 覆盖提取、版本校验、审批与 Outbox。
5. SIGNAL 只报告并解释，不强行设置通过阈值，也不作因果或统计结论。

## 影响

- 保留 ADR-024 删除学术型评测的决定。
- ADR-024 中“P0 仅四项指标”被本 ADR 替代。
- 现有四项核心结果被保留并纳入 GATE 或 EFFECT，而不是删除。
